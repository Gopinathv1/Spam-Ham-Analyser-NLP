# Spam-Ham Analyser — NLP Classification

A text-classification project for identifying messages as spam or legitimate (“ham”) using classical NLP and machine-learning techniques.

## Overview

The project is structured around a practical NLP classification workflow:

1. Text cleaning and normalization
2. Feature extraction from message content
3. Model training and evaluation
4. Classification of new messages
5. Optional API-oriented serving components

## Technology

- Python
- pandas and NumPy
- scikit-learn
- NLTK and spaCy
- joblib
- FastAPI and Uvicorn
- matplotlib and seaborn

## Getting started

```bash
python -m venv .venv
# Activate the environment for your operating system
pip install -r requirements.txt
```

Run the project entry point or API module available in the repository.

## Skills demonstrated

Natural-language processing, text classification, feature engineering, model evaluation, and Python API integration.
